# Código

Implementaciones clave del sistema.

## Archivos

- `collector-endpoint.js` - Endpoint para recibir eventos del cliente
- `event-transformer.py` - Transformer de eventos a formato Meta CAPI
- `meta-integration.js` - Integración directa con Meta Conversions API
- `client-sdk.js` - SDK para cliente (navegador/app)
- `validator.js` - Validador de eventos contra schema
