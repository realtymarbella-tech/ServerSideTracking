# QA Checklist

## Pre-Launch Checklist

- [ ] Todos los eventos capturados correctamente en QA
- [ ] Schema validación pasando para 100% de eventos
- [ ] Meta CAPI recibiendo eventos sin errores
- [ ] Event deduplication funcionando
- [ ] PII hashing correctamente implementado
- [ ] Latencia < 100ms en endpoints
- [ ] Logs en lugar para debugging

## Post-Launch Monitoring

- [ ] CPL dentro de rango esperado
- [ ] CPQL dentro de rango esperado
- [ ] Tasa de error < 0.1%
- [ ] Alertas configuradas para anomalías
- [ ] Dashboard actualizado en tiempo real
